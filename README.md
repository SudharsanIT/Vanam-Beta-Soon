## 🌍 About VANAM

**VANAM** is an AI-powered wildlife intelligence platform designed to support wildlife conservation, environmental monitoring, and human-wildlife conflict awareness.

The platform combines artificial intelligence, location intelligence, digital mapping, and community-driven reporting to provide a smarter approach to wildlife monitoring and environmental protection.

VANAM aims to bridge the gap between people, wildlife, and forest ecosystems through accessible technology.

## ✨ Key Features

### 🐘 1. AI Wildlife Detection
- AI-powered wildlife identification.
- Detection support for multiple animal species.
- Wildlife image analysis and verification.
- Wild Lens camera-based wildlife detection.

**Supported wildlife categories:**
- Elephant
- Tiger
- Leopard
- Bear
- Deer
- Wild Boar
- Monkey
- Snake

### 📍 2. Wildlife Monitoring & Reporting
- Community-driven wildlife sighting reports.
- GPS-based location information.
- Timestamp-based sighting records.
- AI-assisted report verification.
- Wildlife activity monitoring.

### 🗺️ 3. Intelligent Mapping
- Interactive digital maps.
- Location-based wildlife information.
- Map visualization using Flutter Map.
- Offline map functionality.

### 🌦️ 4. Weather Intelligence
- Weather monitoring dashboard.
- Location-based weather information.
- Environmental awareness through weather data.

### 🚨 5. SOS & Safety
- SOS alert functionality.
- Location-aware safety features.
- Emergency-focused user interface.

### 🌱 6. Eco Market
- Dedicated eco-market module.
- Environmental and sustainability-focused marketplace experience.

### 🧰 7. Survival Kit
- Dedicated survival information interface.
- Quick-access survival resources.

## 🚀 Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or VS Code
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/SudharsanIT/Vanam-Beta-Soon.git
```

**2. Navigate to the project**

```bash
cd Vanam-Beta-Soon
```

**3. Install dependencies**

```bash
flutter pub get
```

**4. Run the application**

```bash
flutter run
```

**5. Build release APK**

```bash
flutter build apk --release
```

Configure any required API credentials and service settings locally before running the application.
